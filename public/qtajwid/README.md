## Cara Penggunaan
1. Salin seluruh folder "paket_modul4" ke drive D (atau lokasi manapun)
2. Buka file "modul4_ucapan_cek.html" dengan browser
3. Pastikan browser mendukung Web Speech API (Chrome/Safari)
4. Izinkan akses mikrofon saat diminta
5. Aplikasi siap digunakan!

## Catatan Penting
- Jangan pisahkan file HTML dari folder audio
- Pastikan struktur folder tetap seperti ini
- File audio harus berada di folder "audio" yang satu level dengan file HTML

## Troubleshooting
- Jika audio tidak muncul: Pastikan folder "audio" ada dan berisi file .mp3
- Jika mikrofon tidak berfungsi: Periksa izin browser dan gunakan HTTPS jika perlu
- Browser yang direkomendasikan: Google Chrome, Safari, Edge terbaru

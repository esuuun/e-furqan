PANDUAN FILE AUDIO
==================

Folder ini harus berisi file audio MP3 dengan nama-nama berikut:

IZHAR:
- minhum.mp3 (مِنْهُمْ)
- an-amta.mp3 (اَنْعَمْتَ)
- man-amana.mp3 (مَنْ ءَامَنَ)

IDGHAM BIGHUNNAH:
- mayyamal.mp3 (مَنْ يَّعْمَلْ)
- min-waaq.mp3 (مِنْ وَّاقٍ)
- mim-maal.mp3 (مِنْ مَّالٍ)

IDGHAM BILAGHUNNAH:
- milladunhu.mp3 (مِنْ لَّدُنْهُ)
- mir-rabbihim.mp3 (مِنْ رَّبِّهِمْ)

IQLAB:
- ambihum.mp3 (اَنْۢبِئْهُمْ)
- mim-badi.mp3 (مِنْۢ بَعْدِ)

IKHFA:
- an-shaddukum.mp3 (اَنْ صَدُّوْكُمْ)
- man-dza.mp3 (مَنْ ذَا)
- yanqalib.mp3 (يَنْقَلِبُ)
- an-tazula.mp3 (اَنْ تَزُوْلَا)
- min-kulli.mp3 (مِنْ كُلِّ)

CARA MENDAPATKAN AUDIO:
1. Rekam sendiri dengan bacaan yang benar
2. Gunakan audio dari aplikasi Quran digital
3. Download dari sumber terpercaya seperti everyayah.com atau quranicaudio.com
4. Minta bantuan ustadz/ustadzah untuk merekam

Format audio yang direkomendasikan:
- Format: MP3
- Bitrate: 128 kbps
- Sample Rate: 44.1 kHz
- Durasi: 2-5 detik per file
